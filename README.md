# sump.stream 💧

**https://sump.stream/**

A 24/7 broadcast of every sump on YouTube. Why? Sump.

- Everything is UTC, so the daily reshuffle happens at the same instant for everyone.
- Videos belong to their creators; this site is just an extremely devoted YouTube embed.

## Credits

- **YouTube IFrame Player API** by YouTube, which plays every video in the rotation
